## 🏥 Mental Health Aftercare System

A comprehensive web-based aftercare monitoring system designed to support mental health patients and their families after hospital discharge. This system provides daily tracking and feedback mechanisms for critical recovery parameters.

### Key Features

- **Daily Checklist Monitoring**: Track essential daily activities including:
  - Sleep quality and duration (7-8 hours target)
  - Regular sleep schedule maintenance  
  - Physical activity and outdoor walks
  - Medication adherence (morning and evening doses)
  - Social interaction and mood stability

- **Interactive Rating System**: 5-star rating scales for:
  - Overall sleep quality
  - Daily activity levels
  - Medication adherence
  - Mood and wellbeing

- **Progress Tracking**: Visual progress bar showing completion status
- **Data Persistence**: Local storage for healthcare provider review
- **Mobile-Responsive Design**: Accessible on all devices
- **Family-Friendly Interface**: Designed for easy use by caregivers and family members

### Problem Statement Addressed

Mental health aftercare is as important as medication and treatment. Regular feedback and monitoring of key parameters like sleep, exercise, and medication compliance are critical for successful recovery. This system enables family members to track these parameters daily and provide valuable feedback to healthcare providers.

### Usage

1. Open `index.html` to access the project hub
2. Click "Launch Aftercare System" to access the main application
3. Fill in patient and caregiver information
4. Complete the daily checklist across all four categories
5. Add any additional notes or observations
6. Save the daily report for healthcare provider review
